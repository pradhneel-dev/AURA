# Causal Explorer

The supplied dataset is a synthetic aggregate snapshot without a defensible intervention assignment, treatment timing, outcome follow-up, and confounder design. Therefore AURA does not report causal estimates or use DoWhy/EconML for treatment effects.

The explorer visualizes stored customer records and generated event/indicator graph nodes. Customer aggregate features are source data; event timestamps and event edges are simulated/descriptive. Diagnose outputs are evidence-linked hypotheses with uncertainty. A graph connection, feature association, prediction, or MCIA score is not a cause, treatment effect, retention probability, or ROI. A valid future causal study would need a specified intervention, temporal outcome, confounder set, and documented identification assumptions.
